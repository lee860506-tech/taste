# 준혁이랑 냠냠지도

Next.js App Router + TypeScript + Tailwind CSS 기반 음식점 탐험 사이트. 탐험 화면은 실제 상가정보 음식점 20건으로 시작하며, 가상 샘플과 일반음식점 인허가 데이터는 출처별로 선택할 수 있습니다.

## 실행
Node.js 20.9 이상과 pnpm을 설치한 환경에서 `.env.example`을 참고해 `.env.local`을 만든 뒤:
```sh
pnpm install
pnpm dev --port 3001
```
http://127.0.0.1:3001 에 접속합니다. 이 작업 환경에서는 기존 다른 앱이 3000번을 사용하고 있습니다.
```sh
pnpm typecheck
pnpm build
pnpm start --port 3001
```

## 기능
홈은 제공된 준혁이 일러스트를 동화책 표지로 사용하며, 제공된 음식 심볼 8개를 카테고리와 음식점 화면에 적용합니다. 홈이나 탐험 화면에서 동네를 고르면 소상공인시장진흥공단 상가정보의 해당 행정동을 서버 API로 조회합니다. 기본 동네는 서울 종로구 종로1·2·3·4가동이며, 페이지당 20건입니다. 샘플 20개와 행정안전부 일반음식점 인허가 데이터도 출처별로 선택할 수 있습니다. 이름 검색과 업종 필터는 현재 조회한 20건에 적용됩니다. 카카오 지도는 유효 좌표만 마커로 표시하며 목록과 선택 상태가 연결됩니다. 브라우저 위치 권한을 허용하면 500m·1km·3km 반경을 선택할 수 있습니다. 주변 상가정보는 선택 반경의 사각형으로 서버 조회한 뒤 정확한 거리로 다시 거릅니다.

샘플 음식점은 가상이며 데모 좌표는 실제 위치가 아닙니다. 공공데이터 출처는 카드에 표시합니다. 영업상태는 인허가 기록일 뿐 실시간 영업 확인이 아닙니다. Supabase 테이블과 서버 비밀 키를 설정하면 음식점 목록·상세는 DB에서 읽고, 별도 보호된 서버 동기화 경로로 기존 기록을 갱신합니다. PostGIS 반경 검색은 DB의 저장 좌표를 사용하며 거리순으로 최대 20건을 반환합니다. 설정 전에는 기존 공공데이터 직접 조회로 전환하고 이를 화면에 표시합니다. 찜 목록은 브라우저 로컬 저장소를 사용합니다.
